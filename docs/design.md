# リモートデュエル補助ツール 設計ドキュメント(v0.1 / 2026-11-02)

## 1. 目的

実物のカードを Web カメラ越しに使うリモートデュエルで、次の2つの不便を解消する。

1. **ライフ・フェイズ・チェーンの取り違え** → 両者が同じ状態を見られるようにする
2. **カメラ越しに相手の盤面・カードが読みにくい** → 相手のカメラ映像を手元で自由に拡大できるようにする

## 2. 前提と範囲

| 項目 | 決定 |
|---|---|
| 利用者 | 自分と友人数人(身内のみ) |
| 形態 | Web ページ。ルームの URL を送れば、相手はインストール不要で参加できる |
| 対戦人数 | 1ルーム2人+観戦者4人まで(観戦は後から追加)。席はデュエルの合間に入れ替えられ、ホストも観戦に回れる |
| 音声 | 当面は Discord 通話などを併用(→ 未決事項 Q1) |

**やらないこと**: カードデータや画像の保持、画像認識、効果処理の自動化、ログイン・認証、マッチング、録画。

## 3. 機能

### MVP(最初のリリース)

**ルーム**
- 「ルームを作る」で URL を発行し、相手が開くと接続される
- 再読み込みや切断の後でも、同じ URL から復帰できる

**共有ステータス**
- 両者の LP を表示する。±の入力(例: `-1800`)、半分、任意の値への直接設定ができる
- LP 変更の履歴(誰が・いつ・いくつ)と、1手戻す操作
- ターン数、ターンプレイヤー、フェイズ(DP / SP / M1 / BP / M2 / EP)
- チェーン記録: カード名を自由入力して積み、逆順に解決済みにしていく。ターンの終わりにクリアする
- コイントス・サイコロ: 結果を両者に同時に表示する(片方が振った結果を相手も見られる)

**カメラ共有と拡大**
- 各自が盤面を映すカメラを共有する
- 受信した側は、相手の映像をホイールやピンチで拡大し、ドラッグで移動できる。ダブルクリックで元の倍率に戻る
- **高画質スナップショット**: 受信側がボタンを押すと、送信側のカメラからフル解像度の静止画を撮って送る。動画は帯域しだいで画質が落ちるので、テキストを読みたいときはこちらを使う
- スマホをカメラ専用の端末として、同じルームに参加させられる(PC で操作しながら、スマホを盤面の真上に固定する使い方)
- カメラ端末で映像の向きを 90° ずつ回せる。映像は加工せず、角度だけをホスト経由で配り、見る側で回して表示する(画質を落とさないため)

### 将来の拡張(MVP の後)
- ターンタイマー、音声通話の内蔵、カード名から公式 DB の検索ページを開くリンク

## 4. アーキテクチャ

```
[プレイヤーA ブラウザ] ⇄ WebRTC (P2P) ⇄ [プレイヤーB ブラウザ]
   ├ 映像: MediaStream(カメラ)
   └ 状態: DataChannel(JSON メッセージ)
        ↑ 接続確立時だけシグナリングサーバー(PeerJS)を使う
```

- **フロントエンド**: Vite + TypeScript + React。静的サイトとして Cloudflare Pages か GitHub Pages に置く。カメラの利用には HTTPS が必要だが、どちらも HTTPS で配信される
- **通信**: WebRTC で P2P 接続する。シグナリングにはまず PeerJS の無料の公開サーバーを使い、不安定なら自前のサーバーに切り替える
- **バックエンド**: 置かない(費用ゼロ)

### 状態の同期
- ルームを作った側を正(ホスト)とする。ゲストは操作を「意図」としてホストに送り、ホストが状態に反映して全体を配信する。これで同時操作による食い違いを防ぐ
- 状態は丸ごと送る(小さいので差分にはしない)。各メッセージに `version` を付け、古いものは捨てる
- ホストは `localStorage` に状態を保存し、再読み込みしても続きから再開できる

```ts
type GameState = {
  version: number;
  players: { [id: string]: { name: string; lp: number } };
  turn: number;
  turnPlayer: string;
  phase: 'DP' | 'SP' | 'M1' | 'BP' | 'M2' | 'EP';
  chain: { card: string; by: string; resolved: boolean }[];
  log: { at: number; by: string; text: string }[]; // LP変動・コイン等
};
```

### 拡大表示の作り方
- 送信側は 1920×1080 以上を要求し、`track.contentHint = 'detail'` で、フレームレートより解像度を優先させる
- 受信側は `<video>` に CSS の `transform: scale() translate()` をかけて拡大する。サーバー側の処理は要らない
- スナップショットは、送信側が `ImageCapture.takePhoto()`(使えない環境では canvas でキャプチャ)で撮り、JPEG を DataChannel で分割して送る

## 5. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| NAT やファイアウォールで P2P がつながらない | 一部の回線で接続できない | まず STUN を使う。だめなら TURN を足す(Cloudflare や Metered の無料枠) |
| PeerJS の公開サーバーが落ちる | 新しく接続できない | 自前の PeerServer を無料の PaaS に置けるようにしておく |
| 帯域が足りず動画がぼやける | 拡大しても読めない | 高画質スナップショットで補う |
| ホストが切断する | 状態が止まる | ホストの localStorage から復帰する。ゲストも最後の状態を持っておく |

## 6. 実装ステップ

1. プロジェクトの雛形と、静的ホスティングへのデプロイ
2. ルームの作成と参加、P2P 接続(DataChannel だけ)
3. 共有ステータス(LP、ターン、フェイズ、履歴、戻す操作)
4. チェーン記録、コイントスとサイコロ
5. カメラ共有、拡大とパン
6. 高画質スナップショット、スマホのカメラ専用参加
7. 友人と実際に対戦テスト → 改善

## 画面の方針

印象は「映像が主役の道具」に寄せる。実物のカードの文字と色を読むツールなので、画面が映像より目立たないようにする。

- 目立たせるのは LP だけにする。デュエルで使う電卓に合わせた7セグメント表示で、LP が変わると数えながら動く(動きを減らす設定なら、すぐ切り替える)
- 映像は黒、まわりは明るめのグラファイトにする。色は席の印、LP の増減、警告にだけ使い、強調は白の塗りにする
- カードを枠で囲んで積まず、余白と面の明るさで区切る。絵文字は使わない。影は押せるキーの厚みにだけ使う
- 7セグメントはフォントを読み込まず SVG で描く。本文は BIZ UDPGothic を優先し、ない端末では端末の日本語フォントを使う

似た道具から、次の見せ方を取り入れる。

| 手本 | 取り入れたこと |
| --- | --- |
| SpellTable(カメラで遊ぶカード対戦) | 映像の下の帯をやめて面積を映像に回し、名前と LP を映像の左上に重ねる。視線を映像から外さずに LP が読める |
| lichess の対局時計 | 手番の側の LP だけ点灯させ、もう一方は暗くする。LP の増減は数字の横に少しの間だけ出す |
| Stream Deck(配信の操作盤) | LP の固定額とターンの操作を、押すと沈む大きなキーにする。よく押すものほど押しやすくする |
| SpellTable と Jitsi Meet の入口 | 最初の画面は対戦画面と同じ形にする。左に卓の絵と一文だけ置き、部屋を作る操作は最初の表示に収める。卓の絵に実在のカードは描かない |

配置には次の UI パターンを使う。

| パターン | 使い方 |
| --- | --- |
| モジュールタブ | 常に見るのは LP・ターン・チェーンだけにして、残りを「デュエル」「カメラ」「部屋」「履歴」に分ける。カメラの選択などの状態を保つため、タブの中身は消さずに隠す |
| 段階的開示 | チェーンの解決のボタンはチェーンがあるときだけ、合言葉の作り直しは開いたときだけ出す。LP の固定額のボタンは、入力中は計算結果に替える |
| ブランクスレート | 映像がないとき、映像の枠に次の操作(招待リンクのコピー、自分のカメラの設定)を出す |
| 良いデフォルト値 | LP の入力先は自分。入力欄を1つにまとめ、行を選んで相手に切り替える。入力先の名前は入力欄と計算結果に出す。LP の行は選ぶだけにして、名前の変更は「部屋」タブに置く |
| 通知 | 自分のカメラが未設定のときと勝敗の確定待ちはタブに印を出す。LP が 0 になるか勝敗が付くと「デュエル」タブを開き、勝敗の欄を先頭にする。コインとサイコロの結果は、どのタブでも10秒出す |
