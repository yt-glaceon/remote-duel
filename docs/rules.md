# 公式ルールとの照合(2026-11-02)

公式ルールブック(マスタールール 2020年4月1日改訂版)と、公式カードデータベースの Q&A を読んで、ツールの表記と既定の動きを照らし合わせた結果をまとめる。方針は「用語・表記・既定値を公式に合わせる」までとし、ルールに反する操作を止めることはしない。実物のカードにはルールを上書きする効果があるため。

## 合わせたもの

| 項目 | 公式ルール(要約) | 変更前 | 変更後 |
|---|---|---|---|
| フェイズ名 | ドローフェイズ・スタンバイフェイズ・メインフェイズ1・バトルフェイズ・メインフェイズ2・エンドフェイズ | 履歴に「メイン1フェイズ」のような誤った表記が出ていた | 公式の名前で表示する。ターン欄にも、いまのフェイズ名を出す |
| 先攻1ターン目の流れ | 先攻の1ターン目はバトルフェイズを行えない。バトルフェイズを行わないときはメインフェイズ2もない | 「次のフェイズ」でバトルフェイズに進んでいた | 1ターン目は、メインフェイズ1から「次のフェイズ」でエンドフェイズに進む(フェイズのボタンで直接選ぶことはできる) |
| LP の端数 | LP やダメージに端数が出たときは、四捨五入して整数にする(公式 Q&A) | 入力欄の式の計算は切り上げだった | 四捨五入にした。「半分」のボタンは、もともと四捨五入と同じ結果になっている |

## すでに合っていたもの

- 開始時の LP は 8000
- ターンは先攻から始まり、交互に進む。先攻・後攻はじゃんけんの勝者が選ぶ(ツールでは、先攻のボタンで選ぶ)
- チェーンは後に積んだものから解決する

## 今回は扱わなかったもの(機能の追加になるため)

- 勝敗の条件: LP が 0 になる、デッキからドローできない、特殊な勝利条件。お互いの LP が同時に 0 になれば引き分け
- マッチ: 3回のデュエルで、先に2勝したほうが勝つ。2戦目以降は、直前のデュエルで負けたプレイヤーが先攻・後攻を選ぶ
- 先攻1ターン目のドローなし、エンドフェイズで手札を6枚に減らすといった手順の案内
